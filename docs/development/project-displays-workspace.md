# 项目大屏 B 方案正式改造

状态：**Awaiting acceptance（待验收）**。用户已选择 B 卡片方案；2026-11-16 自测通过，尚未获得人工验收确认。

## 目标与范围

以当前系统的卡片、按钮、状态标记和带遮罩 Drawer 呈现大屏。通过线上版本、工作草稿、访问与数据授权的位置关系表达对象关系，不增加步骤条、流程图或流程教学文案。保留多实例、程序、参数与数据绑定、读取授权、发布、运行、终端与审计能力。

本次只改控制台呈现和相应回归脚本，不变更数据库、API 合约、权限目录或运行服务。当前分支直接修改，不创建分支或 worktree。

## 设计与技术

- React / TypeScript 实现卡片列表和管理详情；复用 `@infrapro/ui` 的 Button、Badge、Dialog、ResponsivePanel 及系统主题，保持桌面右侧抽屉和手机底部抽屉的一致行为。
- 列表增加名称搜索、状态筛选、分批显示（每批 12 个）。仅为可见卡片请求详情；卡片与打开的抽屉共享 TanStack Query 缓存。列表 15 秒、卡片 30 秒、抽屉 5 秒刷新。
- 卡片使用程序图标与实际版本信息，没有截图生成能力时不绘制虚构的实时画面。显示已发布、未发布、停用、归档、授权问题等已知状态；发布状态不等同于运行就绪。
- 概览将线上版本与工作草稿并列；草稿保存不会切换当前发布。按程序、参数、绑定、时间模式汇总差异。配置编辑复用 schema 和真实对象选择器。
- 发布前展示配置对比；核验结果绑定配置编号和实例修订，修订变化后禁止用旧结果提交。历史回退仍创建新发布并核验当前授权。撤回、启停、归档由明确的操作确认保护。
- 访问区域提供稳定入口、人员范围、固定终端入口；数据授权保持独立。普通查看者的精简响应不会被解释成“缺少授权”，不会显示管理详情和写入控件。
- 保留 `?instance=...&package=...` 深链接、浏览器前进后退、Escape 关闭及触发按钮焦点恢复。身份后台复核期间保留表单输入并暂停写入；权限/范围变化由现有 ProjectBoundary 清理缓存并重新挂载。
