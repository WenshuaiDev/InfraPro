# 项目角色 A 方案正式重构

日期：2026-11-15。状态：Awaiting acceptance。用户已选择 A 并授权正式实现；实现与自测完成，待用户人工验收。结果及操作步骤见 [自测与验收记录](../verification/project-roles-redesign.md)。

## 目标与交付

项目角色使用与平台、租户一致的紧凑表格、搜索／来源／状态筛选、分页和带遮罩 Drawer。权限说明整合到角色详情和配置，不再保留独立的项目权限目录菜单；旧目录 URL 跳转到角色页。

保留创建、复制、资料编辑、权限配置、启停、删除、真实影响预览、原因／重新认证、版本冲突与请求重试、成员及历史查看、预置管理员保护、项目归档限制和所有原有授权边界。

## 技术与实现

- React / TypeScript 拆分列表、详情、权限浏览／选择与真实操作表单；使用共享 RoleTable、ListPagination 和 Base UI ResponsivePanel，与平台／租户一致。
- TanStack Router 保留角色详情深链接，列表作为父路由、详情作为 Drawer 子路由；查询参数承载筛选和页大小，关闭详情返回原列表状态。
- TanStack Query 与 useCursorList 使用现有游标 API，按账号和项目权限上下文隔离缓存；不对当前页进行全局筛选，不伪造总量。
- Go / pgx 项目角色查询补充 `source=custom|preset`，在数据库分页前筛选；OpenAPI 和 TypeScript 客户端同步。PostgreSQL 表结构、Redis 和原授权判定不变，无迁移。
- `project.permission.read` 保留原编码和授权范围，中文名称调整为“查看项目权限说明”，描述指向角色内的说明。发布时需执行既有 `access sync` 元数据同步；本地 dry-run 确认仅此 1 项名称／描述变化，0 个角色、0 个租户和 0 个项目授权变化，随后同步并通过 `access check`。
- 真实变更复用已有项目服务，权限／启停／删除先读取服务端预览；提交保留预览哈希、项目／对象版本和请求 ID。预览过期后重新核对，传输结果不明时保留原请求重试。
- 权限展示中文名称、业务分组、用途、敏感标记及管理员保留能力，编码按需显示；搜索支持名称和编码。无法读取目录时显示明确状态，不把缺失说明当成没有权限。
- 移除原型分支与内存模拟、演示入口及启动脚本。A/B/C 原始素材已保存在 `.artifacts/project-roles-prototype/source-before-formal.tar.gz`，SHA-256 `58920ac4832e112a403208c2a7f28d59e0e07fedacbbf96562af8efc11fb38f3`。遵守当前工作约定，不创建分支或 worktree。
- 共享角色菜单拦截自身的 Esc 事件，先关闭菜单，保留底层详情 Drawer；提交期间禁止关闭或重复提交。传输失败或成功状态下的响应解析失败均保留原始请求体与请求 ID，防止重试产生第二次变更。

## 自检与人工验收标准

1. 项目角色表格风格与平台／租户一致；搜索、来源、状态和分页均对完整服务端结果有效。
2. 点击角色打开系统遮罩 Drawer，刷新深链接仍可打开；关闭返回原筛选和页位置，键盘焦点可恢复。
3. 详情展示中文权限、可选编码、基本资料、绑定成员（包括暂停成员）及历史入口；没有权限的区域不读取或显示受限信息。
4. 创建、复制、编辑、配置、启停、删除真实保存并刷新；取消不写入，预置角色只读，管理员不可复制或直接编辑，仍有绑定的角色不可删除。
5. 权限变更展示真实成员影响；归档项目只能撤权／停用等获准操作，预览过期、重新认证和响应丢失有可恢复路径。
6. 独立目录入口及写死数量消失；旧 `/permissions` 地址进入角色页，原权限定义与目录 API 保留。
7. 桌面、375px 手机、横屏、深色主题、键盘与 reduced motion 验看；类型、lint、构建及相关接口／浏览器回归通过。

自测使用隔离数据库与独立测试账号，不对人工验收环境创建临时业务数据。完成后刷新现有本地验收服务供用户验收。自测结果与人工接受状态分别记录。
