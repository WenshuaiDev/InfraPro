## 使用流程

| 使用场景 | 页面行为 |
| --- | --- |
| 复核已完成的分析 | 打开历史分析即进入成果目录。按名称或归档状态找成果，在同一页读取所选版本、输出值、时间和依据状态。按行查看原快照中的候选样本。可按原规则复核的直接运算标出命中样本及相对输出时刻。 |
| 继续上次的工作 | 从成果打开重算，带入固定方案、输出、质量和原时段。可先试算，人工发起完整运行后追加版本。已有版本继续可比较、导出。 |
| 建立一种新分析 | 从新分析选择常用方法及实际通道。自定义输入、步骤、参数、时间与精度分区编辑。保留草稿、服务端校验、固定方案版本及后续运行。 |
| 管理成果 | 归档停止追加版本。删除作用于所选成果的全部版本，提交前展示整份成果名称、版本范围并填写原因。完成后列表、版本链接、关联读取和服务端导出失效。 |

## 实现与验收

React 和 TanStack Router 复用租户、项目工作空间及可分享的成果版本地址。TanStack Query 请求真实的目录、固定输出和来源证明。界面根据当前空间权限展示操作。

Go 服务在同一 PostgreSQL 事务中校验工作空间、权限、操作原因和预期修订，写入删除时间、幂等回执及审计。历史固定数据保留用于完整性与审计，业务入口没有恢复按钮。重算的追加发布和删除按同一成果行串行提交。

验收时可从目录复核一行数据、切换版本，换时段生成新版本，用独立测试成果验证取消删除、版本冲突、成功删除及旧地址失效。原始观测和方案仍可用于另一份分析。

- Go 业务集成覆盖固定版本的多项输出、同距最近匹配、未来基准、项目归档、授权片段和撤权、四万输入的检查点恢复。删除用例覆盖原因、过期修订、重复提交、全部版本、已生成的下载、关联比较和排队中的重算。记录见[业务集成日志](../../.artifacts/historical-analysis-results/final-go.log)。
- 桌面和手机浏览器复核多输出、精确导出、局部时段授权、分位数设置，以及从测点创建分析、换时段重算、归档和删除的完整流程。独立测试成果用 10、12、15 三个数求均值，首个版本为 12.333333 mm，缩短到最后两个样本后为 13.500000 mm。记录见[浏览器回归日志](../../.artifacts/historical-analysis-results/verified-browser.log)。
