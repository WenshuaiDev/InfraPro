# 解析服务实施与验收跟踪

状态：**Awaiting acceptance**。依据：[完整开发规格](parsing-service-and-method-binding-spec.md)。用户于 2026-11-16 授权实施全部范围；人工验收尚未进行。

## 实施方案

交付两个方法、三个固定版本的独立 Go 解析服务，以及 InfraPro 的目录治理、公共／私有产品配置、设备固定采用、样本、运行追溯、对比和任务入口。继承是创建时的快照；所有升级、回退和清空均显式提交并保留历史。

通用契约放在 foundation/parsingcontract；服务通过标准库 HTTP 和受限子进程执行保留摘要的产物。平台 parsing 模块使用现有 pgx／PostgreSQL 事务、设备协调锁、权限和审计机制。S3 存放不可变原始字节与响应；监测 worker 领取 parsing 自有队列，使用代次、租约和 fence 接受至多一次结果。React／TypeScript 控制台使用既有 Query 授权缓存、表格和遮罩 Drawer，不引入新依赖。

内部步骤：契约与固定夹具 → 服务及进程隔离 → 迁移与目录／配置／采用 → S3、worker、任务、API 与界面 → 故障注入、恢复、回归和浏览器验收。完整范围以 PAR-001—PAR-076 为准，各步骤不是独立交付终点。

验收重点：真实 HTTP／PG／S3 链路；默认升级不改变旧设备；配置与运行保留精确产物；越权、并发冲突和迟到响应被拒绝；可从结果追到原字节、步骤和固定配置；正式观测不增加。最终逐项记录环境、操作、结果及证据路径。全部自验通过后才进入 Awaiting acceptance，用户明确确认后才进入 Accepted。
