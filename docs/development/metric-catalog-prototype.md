## 数据与边界

- React、TypeScript 和现有工作空间外壳承载三个布局。TanStack Router 只在开发模式、平台 `metrics` 路由且显式带 `variant=A/B/C` 时加载原型；无参数的现有目录、其他工程页面和生产构建不加载它。
- TanStack Query 使用现有工程读取权限和客户端：按 100 项分批取定义摘要；仅对当前页或直接打开的指标读取详情。目录中的形态、版本、标准单位、范围与枚举来自实际定义，不推断单位或自动换算。可用状态是定义维度；详情按所选版本显示。
- 设施索引是原型导览数据：以已编目指标的稳定编号对应既有七类设施说明，可多选归属；未匹配的定义保留在「未编入索引」。它既不是单位类别，也不是规范化的设施适用性校验。若采用此方向，应再决定正式索引的数据来源。
- 无迁移、无工程写接口。试填值、新建卡片和草稿预演只存在内存中；不执行发布、停用或复制等正式维护操作。本地只核对样例值、边界和单位，不替代服务端发布校验。复用同一域名的受信管理端会话；登录和续期仍归正式入口负责。
