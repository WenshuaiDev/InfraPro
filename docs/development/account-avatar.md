# 账号头像

状态：**Awaiting acceptance（待人工验收）**。2026-11-17 已完成实现及自检；人工验收尚未完成，结果单独记录。

账号拥有一份全局头像。个人资料支持选择 JPG/PNG（原图 ≤5 MiB、≤2500 万像素）、正方形裁剪、拖动/键盘调整、缩放、预览、保存和移除。右上角使用现有 shadcn/ui Radix Avatar + DropdownMenu。账号菜单、个人资料、平台账号、租户成员、项目成员的列表及详情统一展示，缺失或加载失败回退到姓名前两字符。

React/TypeScript 与浏览器 Canvas 负责本地裁剪，上传规范化的方形像素；Go 仍独立检查输入字节、解码格式和像素上限，生成 256×256 PNG 并丢弃元数据。图片处理并发上限为每 API 进程 2 个。PostgreSQL 保存当前引用、单调版本和对象状态，已有 S3 适配器使用独立 `account-avatars/v1/` 命名空间。先登记暂存意图、上传并核验实际字节，再原子切换引用和写入审计。写入按版本比较，过期页面不会覆盖新头像。失败上传一小时后、旧头像 24 小时后回收；后台清理可重试。

更换和移除沿用 `account.profile.update`；本人头像读取需要有效登录。平台、租户、项目图片读取分别沿用账号详情、租户成员详情、项目成员详情的权限，并检查目标所属范围。图片读取前后检查身份、权限及当前版本，不返回对象存储地址；正文不持久缓存。API 契约、客户端类型、反向代理上传限制同步更新。

验收：横竖图片裁剪一致；保存、刷新、重登、跨空间展示一致；移除恢复默认；取消/无效/失败保持原图；禁止越权读写；权限撤销和账号切换清理前端图片；旧账号兼容；键盘和移动端操作可用。验证结果与备份恢复步骤见 `docs/verification/account-avatar.md` 和 `docs/operations/account-avatar.md`。
