## 设计与技术

- TypeScript / React 19 实现正式页面；TanStack Router 的 `section` 查询参数表达任务入口，保留原 `asset/version/owner/owner_kind/facility/page/view/mode` 深链接语义。查询条件与选定上下文进入 URL，刷新及返回可解释。
- TanStack Query 继续调用现有同源 Go API；缓存键沿用账号、租户／项目、权限修订与版本隔离。失权清理、迟到响应及权限交集继续由原边界负责。
- Tailwind 与共享 UI 组件保持现有管理端主题、密度和响应式行为。资料详情、发布及授权预览采用共享 `ResponsivePanel`，具备遮罩、键盘关闭和焦点返回。
- OpenLayers 继续承担二维地图与 GeoJSON；Three.js 继续承担模型与表面点选；既有 Canvas 布设图查看器继续承担图页、区域及标记交互。只调整工作区组织和明确控制，不替换已验证的格式处理链。
- PostgreSQL、对象存储和空间 worker 沿用既有实现；监测与成果复用现有接口。本轮不新增空间业务身份，不修改数据库存储规则。
- 自验使用独立空间演示环境和已有合成资料，通过真实 API 上传、处理、保存、发布及授权。现有个人验收环境只做页面读取验证；不清空或重置其数据。
