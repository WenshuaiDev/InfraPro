## 目标与实现

采用紧凑表格展示文件名称、类型、大小和更新时间。查看附件、上传记录和添加文件均通过现有 `ResponsivePanel` 打开；该组件使用统一的 `Drawer`，包含遮罩、移动端适配、关闭和焦点恢复。

附件概览展示预览、必要元数据、说明和下载入口；编辑、替换、版本历史、还原、回收/恢复以及技术信息按需展开。普通附件、上传与待处理、回收站及租户/项目资料入口均保留。名称和日期筛选继续使用现有服务端查询与游标分页，原型中仅作用于已加载数据的类型筛选与排序不作为正式全量筛选提供。

使用现有 React / TypeScript、TanStack Query / Router、Tailwind 及 shadcn/ui 组件。保留 Go 文件服务、数据库和对象存储协议；真实写入继续提交操作原因、预期修订、恢复代次和幂等请求标识。权限、项目归档和文件完整性决定可用动作。PNG/JPEG 读取授权安全预览，其余格式沿用下载能力。

实现步骤：表格与 Drawer 组织 → 分离概览/历史/管理操作 → 上传与续传整合 → 移除原型入口 → 类型、Lint、构建与真实服务浏览器回归。

## 必须保留的能力

- 租户、项目及资料页共用附件身份和权限边界；搜索、日期、游标加载、回收站和管理范围上传列表。
- 新建、暂停/续传、失败重试、取消未提交上传、需要处理时重新确认；固定代任务和本代结果入口。
- 改名/说明、替换、当前及历史下载、图片安全预览、版本翻页与还原为新修订。
- 回收、恢复、不可恢复状态提示；操作原因、CAS 修订冲突、幂等回执、权限裁剪和错误恢复。
- 附件/历史版本/上传审计入口、摘要与处理报告等技术信息。

## 验收预期

1. 点击列表文件出现系统风格的 Drawer 与遮罩，背景列表位置、筛选不改变；关闭回到触发位置。
2. 默认概览没有 UUID、SHA-256、编辑表单和展开的全部历史；按需入口均可达。
3. 在隔离样本中真实上传、改名、替换、还原、回收和恢复后，刷新仍保留结果；历史和下载摘要正确。
4. 读、下载、管理权限分别生效，归档/维护/异常状态不提供失效操作。
5. 375px、200% 缩放、键盘和深色下主要操作可达，遮罩与抽屉样式与系统其他页面一致。
