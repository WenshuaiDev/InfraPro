# 设施类型详情 · 方案 B 实施与验收

方案 B 已确认并接入本机管理端。状态为待人工验收。

## 详情与维护

从「工程配置 → 设施类型定义」选择一个类型，即可查看建档结构示意。点选对象能看到它的用途、上级和建档资料。首页的树展示一种布设示例，完整定义可以在「查看全部结构规则」中查阅。

- **工程结构规则**按对象展示。以涵洞的「涵身」为例，上方显示可归属的设施和数量要求，下方显示可包含的八类构件。点一个子构件可以继续查看它的上级、下级和字段。窄屏使用对象选择器。
- **版本与管理**集中办理草稿编辑、保存、样例验证与发布。有多个版本时可以切换时间线，选择对照版本查看差异。停用、恢复、复制独立定义和删除草稿放在「更多操作」。操作记录显示当前定义的变更、经办人、时间和原因。
- 从已发布对象选择「建草稿编辑规则」，建立草稿后会回到原来的对象。编辑中关闭抽屉仍可继续。离开详情前会提示处理未保存的输入。

React 和 TypeScript 实现界面，TanStack Query 和现有工程 API 客户端读取定义、版本差异、引用影响与审计记录。保存、发布等操作由 Go 工程配置服务写入 PostgreSQL。每次写入携带变更原因和请求标识。修订号发生冲突时保留本页输入，由编辑者决定何时读取最新稿。写入回执丢失时可核对原操作结果。

## 手动验收

1. 打开涵洞规则，选择「涵身」和一个子构件，核对归属及数量。打开「建档资料」查看该构件自己的字段。[涵洞结构规则](http://localhost:25173/platform/engineering/type-definitions?definition=7cf14795-7cfd-49b5-a2b7-b02bddc095ce&panel=structure)
2. 回到首页打开「版本与管理」，展开发布说明并查看操作记录；在气象站详情选择「站坪测点」，核对它直接归属气象站以及对应的通道示例。[涵洞版本与管理](http://localhost:25173/platform/engineering/type-definitions?definition=7cf14795-7cfd-49b5-a2b7-b02bddc095ce&panel=versions) · [气象站详情](http://localhost:25173/platform/engineering/type-definitions?definition=149b6ea0-1e7b-4aa8-8e67-92fbd169254d)
3. 在一个测试类型上从 V1 建立草稿，修改构件数量并填写原因，保存后刷新。再次打开应能读到已保存的值。校验通过后发布 V2，使用「版本对比」核对数量变化，切回 V1 可查看原值。

本机管理端已运行。需要重新启动本地环境时，可在仓库根目录运行 `pnpm local:start`。
