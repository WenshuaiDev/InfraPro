# 统一任务中心 · 列表与详情

当前工作区已实现并完成自验，待用户验收。[验收记录与复验步骤](../verification/task-center-list-detail.md)

用户已选定方案 B。顶栏「任务」是统一入口。工作台负责提交业务，回执定位任务，任务详情负责跟进本次执行并打开成果。

## 页面与接口

React 与 TanStack Router 将任务编号、执行代次、视图、筛选和运行概况写入地址。宽屏左右并排，小屏从列表进入详情。工作空间入口携带租户或项目的精确范围。旧任务和运行地址按原业务标识解析，已有成果地址保留版本参数。

TanStack Query 使用正式任务列表、汇总、类型目录、详情和控制接口。统计覆盖当前筛选下获准的全部记录。缺少完整统计时显示待核实。Go 业务服务在打开结果时再次核对权限，以运行和发布版本的关联定位成果。自动计算在运行概况中按空间分页，沿用计算运行的读取、取消和重试资格。

## 验收路径

1. 从租户和项目工作台打开本空间任务，核对范围，切换个人和管理视图，筛选和翻页后核对服务端计数。
2. 分别在桌面和手机提交业务，从回执进入本次任务并打开本次成果。再次发布同一成果后，旧任务仍打开原版本。
3. 从运行概况查看自动运行的时段、失败原因与可用控制。取消后同一输入和委托下的本次时段保持已取消，其他时段仍可调度。手动重试沿用原运行编号与目标，成功后核对发布代次。
4. 打开旧任务、计算运行和历史通知目标，核对对象与执行代次。检查已完成但结果受限的展示。
