# 账号中心页面设计

个人资料和账号安全采用已选定的 B 方案。通知中心沿用相同的横向导航、概览卡片和内容宽度。工作空间返回入口保留进入账号中心前的上下文。

| 正式入口 | 首屏 | 进一步操作 |
| --- | --- | --- |
| 个人资料 | 账号名片、显示名称、绑定的平台角色 | 裁剪或移除头像、保存名称 |
| 账号安全 | 验证器状态、当前会话、最近三条安全记录、登录密码 | 管理验证器和恢复码、查看或退出会话、翻阅记录、修改密码 |
| 通知中心 | 全账号未读数、租户邀请和接收设置入口、单列收件箱 | 按状态、分类、来源筛选，按页查找，打开独立详情，返回原列表 |

平台账号管理的账号详情提供「有效权限」页签，可核对权限名称、编码和授予角色。个人资料仅展示平台角色名称及停用状态。

三个页面使用 React 和 TypeScript 共用导航与卡片样式。TanStack Router 管理页面、通知筛选和游标。TanStack Query 与现有 API 客户端读取和更新真实账号数据。敏感操作沿用服务端的密码确认、版本校验和会话失效规则。通知详情加载成功后才提交已读回执，接受邀请仍须用户主动操作。

## 人工验收

1. 在个人资料修改名称并刷新，核对名片、顶栏和角色。进入平台账号管理，在目标账号的「有效权限」中查找授权来源。
2. 在账号安全查看当前浏览器和最近三条记录，打开会话、完整记录和验证器管理。更换密码或退出会话可在测试账号上体验。
3. 在通知中心筛选并打开一条通知，返回时核对筛选、页码和滚动位置。检查邀请、接收设置以及手机窄屏的导航和详情。

构建及浏览器自验结果见[账号中心重构自验](../verification/account-center.md)。
