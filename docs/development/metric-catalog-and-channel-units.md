# 指标目录与监测单位

平台指标目录采用 B 方案，按设施浏览。详情采用 A 方案，左侧展示记录规格，右侧展示适用说明和样例入口。单位类别由单位目录维护。

## 指标编制与版本

数值指标引用单位目录中已发布、可新采用的单位版本。可以关联多项，并指定其中一项为标准单位。第一项自动设为标准，编制人可更换。单位类别由第一项确定，后续候选按该类别筛选。例如，长度类别中的米只有加入当前指标的允许集合后才能用于此指标。枚举指标记录选项编码，单位为空。

已发布的指标版本固定标准单位、允许单位、取值边界或枚举选项。修改先建立草稿，再校验、发布新版本。已有通道继续引用建档时选定的指标版本和单位版本。新建通道默认带出标准单位，用户可以改选同版本允许的其他单位。

## 业务采用

| 入口 | 行为 |
| --- | --- |
| 租户与项目原始通道 | 确认指标版本后列出它允许的单位。切换指标时重新计算候选和默认单位。切为枚举时清空单位。 |
| 设备产品、设备输出和绑定 | 输出配置采用同一允许集合。绑定以固定版本匹配，解析按实际选定的单位读取符号。 |
| 监测模板 | 每个绑定要求独立指定指标版本和其中一个允许单位。 |
| 派生指标和分析输入 | 限定公共指标时，使用它的固定单位，按原单位幂次采用。未限定公共指标的输入和常数可以独立声明量纲。 |
| 文件导入、查询和比较 | 导入映射沿用目标通道的单位。文件映射了单位列时，数值行必须与通道符号一致，枚举行留空。数值按通道单位保存和展示。绝对值比较依据固定单位版本及派生量纲分配坐标轴。 |

当前单位目录记录名称、符号与类别。它没有换算系数或偏移量。数值边界作用于记录原值，例如 12.5 cm 的记录按 12.5 检查并保存。采集方如需更换单位，应提供相应单位的数值并选用匹配的通道。

## 实现

React 和 TypeScript 实现目录、规格表、版本维护和单位选择。TanStack Router 保存目录筛选、页码与每页条数。TanStack Query 按当前权限读取指标与单位版本。设施标签来自指标版本，历史定义兼容说明中单独列出的“适用设施”。缺少标签的指标进入“未归类”。设施标签用于查找，通道采用仍由目录权限与版本状态决定。

Go 工程服务在已有授权事务中提供目录分页、设施计数和单位候选。PostgreSQL 从当前已发布版本读取摘要，仅有草稿时读取草稿。设施计数基于完整的搜索和状态筛选结果，多设施指标可计入多个分组。允许单位继续存储为不可变的单位版本引用，服务端在发布和业务采用时核对引用。本次调整无需数据库迁移。

## 本机验收

1. 在指标目录选择“隧道”，搜索“照度”。打开后应能看到记录规格、勒克斯及样例入口。返回目录应保留设施与搜索条件。
2. 打开“位移”，在“版本与管理”中选 V1 和 V2，关闭面板后对照允许单位。当前本机数据中，V1 只有毫米，V2 有毫米、厘米、米。
3. 在测试环境新建一个仅关联毫米和厘米的数值指标，将厘米设为标准单位并发布。为测点新增业务通道，选用该指标版本，默认应为厘米，也可以选毫米。米应不在候选中。
4. 将测试指标的新版本改为只允许毫米。通过原先的厘米通道查看历史记录，原通道仍显示厘米。
