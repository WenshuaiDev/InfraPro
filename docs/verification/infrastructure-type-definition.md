## 3. 方案 SV-01–SV-21 证据

| 编号 | 覆盖和观察结果 |
| --- | --- |
| SV-01 任意新类型 | E2E 在同一启动构建上创建路基路面、两种合法构件数量样例、公共模板、租户副本和 V2；再使用随机未知编号发布另一种类型。流程期间不改源码、不迁移、不重新部署 |
| SV-02 元模型边界 | 严格 JSON 输入、未知/脚本字段、客户端指定范围、CSRF 负向；八种有限属性形态；远程加载器关闭，应用只生成自身 Schema；无按业务类型名称分支 |
| SV-03 两端一致 | 29 组共享样例全部一致：0、false、缺失/null、空白、Unicode、真实日期、时区、边界、枚举/多选、默认值不注入；校验不修改输入 |
| SV-04 构件规则 | 不可达类别、关系环、数量、缺失父级、非法父子、重复节点/父级、样例环、必需节点及过量构件拒绝；浏览器实际增加构件并验证 0/负数 |
| SV-05 指标单位 | 发布固定单位，指标标准/允许单位范围，量纲不兼容拒绝；枚举样例与数值形态校验；类别引用后数据库保护 |
| SV-06 多目标映射 | 两个类型版本分别验证；遗漏映射不能发布，把第一类型类别键用于第二类型被拒绝；改为第二类型根对象后可发布 |
| SV-07 不可变历史 | V2 不改 V1；租户模板仍解释原名称和字段；数据库禁止发布正文更新；字段键删除后隔版本复用为其他形态被拒绝 |
| SV-08 独立复制 | 公共与私有版本拥有不同身份；公共来源模板停用后副本仍可新使用；固定来源摘要保留名称、编号、版本 |
| SV-09 完整依赖 | 单位停用沿指标/类型/模板传递，副本不绕过；已有私有历史仍可预览，租户公共目录隐藏不可新采用版本；恢复依赖后重新可用 |
| SV-10 无审批 | 同一有权用户保存并直接发布；没有审批表、路由、状态、菜单或权限；确认对话框只确认业务动作 |
| SV-11 发布权限 | 自定义仅查看/编辑角色，UI 无发布操作、直接服务及 HTTP 发布拒绝；非法结构即使有发布权限仍失败 |
| SV-12 租户隔离 | A 私有模板对 B 的列表/搜索、详情、预览、差异、影响与复制均不可读；仅有平台资格的账号也无私有详情；来源和依赖解析不跨范围 |
| SV-13 当前资格 | 新请求事务中复验账号会话、租户、成员及角色；工程测试实测角色撤销、收据重放/查询拒绝和租户停用；完整身份/租户/成员回归覆盖账号停用及成员结束 |
| SV-14 编辑/发布并发 | 相同旧修订两次保存仅一个成功；相同发布请求并发返回同一版本；草稿消费、发布递增；冲突输入无法覆盖 |
| SV-15 发布/停用竞态 | 两个真实不同账号、数据库锁队列控制先后：停用先行则发布 409 且无版本；发布先行则保留成功版本，但停用后不可新使用 |
| SV-16 幂等与回滚 | 相同请求一条成功审计；相同 ID 不同载荷冲突；失败审计注入使整个发布回滚、草稿保留、收据不存在，恢复后同请求成功；删除重放和编号墓碑测试 |
| SV-17 前端上下文 | 独立账号/租户/成员查询键及客户端代次；失权后重新加入通过当前资格重查发现新关系，旧响应不回填；503 保留本地编辑且无自动写重试，真实角色撤权清空页面；现有账号切换/成员重新加入/租户切换回归共同覆盖 |
| SV-18 审计范围 | 平台即使持有租户审计能力也读不到私有工程事件；A 租户审计看到自身创建，事件与业务同事务；详情审计 tab 在桌面和移动端实测 |
| SV-19 增量迁移 | 新测试库完整建表；v7 存有项目/成员/角色/凭证的数据库升级，存量逐表保留；本机实际备份恢复和迁移见第 4 节 |
| SV-20 部署/CSP | 实际 Docker API/CLI/Nginx 构建、普通非安全 HTTP；`/console/` 新工程深链接刷新、false/Unicode 默认值动态表单及服务端预览通过；浏览器无 CSP 和运行错误 |
| SV-21 范围 | 页面明确“样例预览，不创建正式设施或监测数据”；无真实资源表和运行入口，无视频/告警演示、配额、审批；源码名称检索无硬编码业务类型 |
