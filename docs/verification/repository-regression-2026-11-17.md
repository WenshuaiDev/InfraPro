## 已确认的根因与变更

- 迁移测试把“最新迁移 Down”当成租户历史不可回退边界；改为直接调用租户迁移版本 3，并验证拒绝原因及当前迁移版本未变化。
- 空间关系测试在创建测点后仍使用结构版本 1；改为读取当前设施结构版本后创建构件。
- 全模块入口没有启动真实解析服务；启动隔离 parser，并在结束时清理。异步等待测试进程，持续消费服务输出。
- 设备／绑定产品发布夹具补充明确的“未分类”选择；工程测试对齐监测锚点与构件类别；设施搜索包括断面和孔位；项目摘要包括新增实体计数。
- 测点移动测试改为正式的“选择目标 → 预览 → 确认提交”流程，验证确认前零写入、确认后唯一写入和归属持久化；移除已经取消的旧文本断面入口操作，保留现行位置验证。
- 权限目录查询反复构造完整目录、角色和路由策略，造成大量临时分配；新增发布期静态索引和校验值复用，返回独立权限切片，保留实时账号、角色、成员和授权检查。相同目录查找基准从 1,748,903 ns/op、3,865,186 B/op 降至 45.40 ns/op、16 B/op；这是局部基准，不能等同于系统整体吞吐量。
- 大屏递归输入证明在同一事务反复解析相同通道授权时段；仅在持有共享授权锁的事务内复用，以服务、会话、通道集合和历史能力区分，并深拷贝返回值。后续分页和请求继续重新校验。固定统计用例 SQL 调用从 414,421 降至 280,438，增加 350,000 次预算回归，防止重复工作反弹。
- 派生试算与统一任务卡片同时显示“已完成”时，旧文字定位会命中两个元素；改为核对唯一的试算完成标题，保留实际计算成功的断言。
- 项目和租户用例硬编码了旧权限目录数量；改为验证当前权限完整性、禁止跨作用域权限，以及十项项目治理权限／九项租户管理员权限不可授予自定义角色。租户角色清空后项目权限仍独立、审计无泄漏、角色叠加与邀请失效的业务断言全部保留。
- 新标签页恢复身份时，启动页品牌标题会误满足“主区标题可见”；退出辅助函数先等待认证后的账号按钮，再等待首页落地内容，避免菜单被首页跳转卸载。
- 移动端监测比较用例在时间面板关闭但焦点尚未归位时操作图例，第二次回车实际重新打开时间面板；改为等待焦点回到“自定义时间”再验证图例键盘开关，没有增加等待时长或重试次数。
- 工作空间导航中的项目治理用例仍操作改版前的直达链接与筛选按钮；对齐现有卡片、授权抽屉、负责人选择和默认“全部状态”，保留授权目标、管理员缺位过滤、归档过滤和详情核对。
- 普通预览、HTTP 大屏与 HTTPS 检查曾共用 `apps/console/dist`；并行的 `/console/` 构建会让根路径预览的脚本请求变成 404。三个入口现在各自构建到独立目录，普通 E2E 每次生成唯一目录；中断信号传递到 Playwright 进程组，避免只停止 pnpm 而留下测试进程。
- 隔离构建继续调用 Console 原有构建流程，保留文档预览资源准备、路由生成和 TypeScript 检查；开发入口也保留资源准备。
- 真实 Docker 诊断测试把 stderr 与容器 ID 合并，镜像拉取信息／警告会破坏 ID 比较及清理；改为只读取 stdout。在真实 Docker 前注入成功命令的 stderr 提示，旧实现失败、修复后通过；失败遗留的本轮容器已按所属标签清理。
- 全模块 Go 采用自动发现清单、每批 8 项、默认双任务并发；每批保留 race（原有实时时限审计用例除外），独立设置包时限，逐项核对完成结果。进程退出成功但缺失用例也判为失败，结束或中断时关闭解析夹具和子进程。

## 人工验收

本轮修改已保存在当前工作区，没有提交或推送。未重启或重建用户现有业务环境，没有新增本轮业务数据迁移；上传限额任务的迁移属于另一项工作。

人工验收前按[本地环境手册](../operations/local-environment.md)核对当前版本及上传限额任务的迁移状态，再使用 `pnpm local:start` 或 `pnpm local:restart` 加载当前构建。访问 `http://localhost:25173`，沿用现有账号，不重新 bootstrap。

1. 发布设备产品时明确选择分类或未分类；预期正常发布，分类规则不被绕过。
2. 移动设施中的测点，先选择归属并预览；预期确认前归属不变，确认后仅保存一次并显示新归属。
3. 在项目治理中使用负责人、运行中、归档及管理空缺筛选，打开授权抽屉；预期筛选正确，授权入口指向当前项目。
4. 新标签页退出、重新登录；切换账号后检查资料／会话／邀请内容；预期旧账号内容不回流，其他设备会话按操作范围保留。
5. 移动端监测比较选择全部历史后用键盘开关图例，并检查审计分页和大屏统计；预期面板焦点正确、查询正常、权限变化立即按现有规则生效。

正式 HTTPS 入口仍按[HTTPS 运维手册](../operations/https-deployment.md)另行安装正式证书及验收。未进行生产部署、真实 systemd 多机安装、生产容量或长时间稳定性认证。
