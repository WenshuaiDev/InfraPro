# 工作空间侧栏分组与间距

日期：2026-11-10

状态：**Accepted**（已验收）

用户人工验收：2026-11-10 确认通过。

## 本轮范围

解决各工作空间侧栏菜单拥挤、缺少职责分块的问题。沿用 shadcn-admin 的轻量分组标题和组间留白，将现有入口组织为：

| 页面范围 | 分组及入口 |
| --- | --- |
| 平台工作空间 | 组织管理：租户管理；账号与权限：账号管理、账号开户邀请、角色管理、权限目录；审计记录：平台审计 |
| 租户工作空间 | 租户与项目：租户资料／本人租户授权、项目治理；成员与权限：成员管理、成员邀请、租户角色、租户权限目录；审计记录：租户操作记录 |
| 项目工作空间 | 项目信息：项目资料／本人项目授权；成员与权限：项目成员、项目角色、项目权限目录；审计记录：项目操作记录 |
| 账号公共页面 | 概览：首页；工作空间：我的租户、我的项目 |

各组仍按当前账号在当前空间的权限筛选，空组不显示。账号资料、安全入口继续由账号菜单提供；空间切换方式沿用已验收方案。

## 实现

- React／TypeScript：`apps/console/src/config/navigation.ts` 输出分组目录，供侧栏、页面搜索和平台默认入口复用。先筛选权限、再移除空组，确保仅有部分权限的账号仍能进入首个可用的平台页面。
- shadcn Sidebar／Tailwind CSS：在共享 `packages/ts/layouts/src/admin/admin-layout.tsx` 中统一使用桌面 40px、手机 44px 菜单行高，12px 图文间距，20px 组间留白；手机相邻菜单保留 8px 间距。标题、图标与文字按统一内边距对齐。
- 继续使用 SidebarProvider 和现有 Zustand 布局偏好。折叠后保留图标、工具提示及组间留白；导航可纵向滚动，顶部切换器和底部账号菜单固定在导航之外。
- 使用带名称的导航分组及当前页语义，装饰图标不重复朗读。沿用现有主题变量和键盘交互。
- 本轮仅调整前端导航数据和共享布局，无新增依赖、后端接口、数据库或数据迁移。

## 启动与验收步骤

仓库根目录运行 `make dev`，访问 <http://127.0.0.1:5173/platform/tenants>。已有服务运行时直接刷新。

1. 在平台、租户、项目之间切换：侧栏按上表显示分组，组间留白明显，组内菜单易于扫描，当前页保持高亮。
2. 返回账号首页：显示“概览”和“工作空间”两组；账号菜单仍能访问个人资料和账号安全。
3. 收起侧栏：图标对齐、组间仍有区分；悬停显示名称，点击可正常进入页面，再展开恢复完整标题。
4. 使用手机宽度打开侧栏：菜单容易点击，长导航可滚动，切换页面后抽屉关闭，无整页横向溢出。
5. 切换浅色和深色主题：分组标题、菜单、选中项保持可辨识；打开页面搜索，目录分组与当前空间一致。
6. 使用权限较少的账号：只出现有权访问的菜单，没有空标题或跨空间入口。
