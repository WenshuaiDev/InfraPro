# 工作空间切换与菜单隔离

日期：2026-11-10。状态：**Accepted**。本轮实施、自验及用户人工验收已完成，人工验收结论与自验证据分开记录。交付时改动保留在本地工作区，未提交、推送或部署生产。

## 本轮范围

- 左上角使用工作空间切换器，参考 [shadcn-admin 的切换交互](https://github.com/satnaing/shadcn-admin/blob/main/src/components/layout/team-switcher.tsx)。平台独立分组，租户分块，项目缩进到所属租户下面；当前空间显示勾选标记。
- 平台导航仅包含当前账号获准的租户管理、账号管理、账号开户邀请、角色管理、权限目录、平台审计。
- 租户导航仅包含本租户获准的资料、角色、权限目录、成员、邀请、操作记录和项目治理。项目治理属于租户职责。
- 项目导航仅包含本项目获准的资料、成员、角色、权限目录和操作记录。平台管理和租户治理均不进入项目导航。
- 页面搜索采用同一空间的功能目录，加账号首页、个人资料和账号安全快捷入口。账号公共入口保留在顶部、侧栏底部的账号菜单中。
- 账号首页、个人设置、“我的租户／我的项目”属于公共页面，显示 InfraPro／选择工作空间，不构造第四种业务空间。选择平台后进入首个有权访问的平台页面，租户和项目分别进入资料或本人授权页。
- 列表仅来自当前账号的“我的租户／我的项目”。不可进入的关系显示不可用状态；项目入口独立使用项目的 `can_enter`，不要求用户同时拥有租户业务权限。归档且仍可访问的项目显示“已归档”。

## 实现

React／TypeScript 组件位于 `apps/console/src/app/workspace-switcher.tsx`，通过共享 `AdminLayout.workspaceSwitcher` 插槽放在 SidebarHeader 中。复用现有 shadcn/Radix DropdownMenu、SidebarMenuButton 与 Lucide 图标，支持键盘、折叠侧栏、移动侧栏和亮暗主题。

TanStack Query 在打开菜单时读取并刷新两个现有接口：`GET /account/tenants`、`GET /me/projects`。按账号隔离缓存，分别保留游标分页、错误重试与空状态；每页最多 50 条。项目按 `tenant_id` 归入租户，项目父租户尚未加载时只显示分组，不推断租户访问权。

TanStack Router 和 `config/navigation.ts` 从 URL 推导当前范围，不使用跨标签页的全局空间选择。刷新、深链接、前进后退均跟随 URL；业务权限仍由现有服务端、租户及项目边界校验。Shell 按查询键订阅边界加载的上下文，通过 TanStack 的批量通知同步标题、菜单，避免在范围清理后继续观察已移除的查询。移动端复用外层 Sheet 的模态行为，切换菜单不另加模态点击锁。没有新增存储或数据库迁移。

## 启动与验收步骤

仓库根目录运行 `make dev`，访问 <http://127.0.0.1:5173/>。已有开发服务正在运行时直接刷新，无需重新初始化账号或数据库。

1. 点击左上角：平台独立成组，租户各自成块，已有项目位于所属租户下；无平台权限的账号不显示平台入口。
2. 选择平台：左侧只显示有权限的平台菜单；账号开户邀请位于此处。
3. 选择租户：左上角显示租户名，左侧仅显示该租户的功能，平台菜单消失。
4. 从同一列表直接选择项目：左上角显示项目名及所属租户，左侧仅显示项目功能；租户角色、成员邀请、项目治理等不出现。
5. 打开页面搜索：只提供当前空间功能和账号公共入口；搜索“账号开户邀请”不应在租户、项目空间找到结果。
6. 刷新、浏览器后退，再在两个标签页选择不同空间：名称、菜单与当前 URL 一致，互不切换。
7. 折叠侧栏或使用窄屏打开导航：仍能打开切换器并完成选择；键盘 Enter／方向键／Escape 可操作菜单。
8. 无可用关系时显示空状态；不可用关系不能直接进入；可通过菜单底部“我的租户／我的项目”查看状态。较长列表能滚动并继续加载，完整搜索继续使用这两个列表页面。

本轮仅交付当前已有功能的导航入口。切换器暂不提供内嵌名称搜索；没有项目数据时不会显示演示项目。用户已确认本轮视觉与操作方式。
