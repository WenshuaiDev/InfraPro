## 验证边界

- 这轮验证原型是否可运行、是否足以比较导航方案，不替代正式实现的回归测试。
- 未做完整权限矩阵、无成员账号、超过 50 条分页、多标签页和深链接登录的全量回归；正式重构按方案再验证。
- 未完成所有暗色、平板、屏幕阅读器和各浏览器组合的视觉验收。
- Google Chrome 控制工具连接超时，浏览自动检查改用项目 Playwright Chromium；用户实际 Chrome 体验待人工评审。
- 原型依赖正在运行的验收 API（28080）。需先在同一浏览器的 localhost:25173 登录；25179 本身不提供业务写操作和登录提交。
- 保留业务页现有内容，因此部分页面仍有「切换项目 / 返回我的租户」原文，原型通过兼容路由接住；正式实现需要按方案统一入口和文案。
- 构建存在既有 Node / Router 工具警告和大分包提示，构建成功；本轮不扩展为打包优化。

推荐 A 的结论仍是待用户评审的设计建议，不能把上述自验证记作用户接受。
