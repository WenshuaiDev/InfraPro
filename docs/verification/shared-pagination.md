# 系统列表分页验收

2026-11-18，自验通过，待用户验收。

## 界面行为

控制台和独立诊断使用同一套分页底栏。总数按当前授权和列表筛选计算。每页条数可以调整，调整后从第一页开始。当前页显示描边，页数较多时显示省略号。首页禁用上一页，末页禁用下一页。空结果显示“共 0 条”。

「切换工作空间」弹窗采用滚动列表。可以直接浏览或搜索全部已授权的租户和项目，接口分批返回的选项会自动合并。

[shadcn/ui Base Pagination](https://ui.shadcn.com/docs/components/base/pagination) 提供页码、方向按钮和省略号的组件结构。共享的 React 底栏负责记录总数和每页条数。返回总数的接口直接使用服务器结果。通知中心在服务端按可见范围一次计算总数和各页起始游标，直接跳页。其他只提供游标的接口按当前筛选分批统计，统计期间显示进度，统计失败可以重试。

## 手工验收

1. 登录后打开工程字典或账号列表，核对底栏总数并调整每页条数。
2. 在有多页的结果中点击页码、上一页和下一页，检查当前页描边和表格记录。进入末页后，下一页应禁用。
3. 在第二页修改筛选条件，核对首页编号与匹配总数。搜索不存在的记录时，底栏应显示“共 0 条”。
4. 缩窄浏览器或使用手机重复翻页，检查底栏和每页条数选择器都可操作。

本地验收入口为[账号管理](http://localhost:25173/access/accounts)、[工程单位目录](http://localhost:25173/platform/engineering/units)和[独立诊断](http://127.0.0.1:8096/components)。
