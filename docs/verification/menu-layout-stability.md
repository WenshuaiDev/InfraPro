# 菜单开关时的页面横向位移

日期：2026-11-10

状态：**Awaiting acceptance**（自验通过，等待用户人工验收）

## 问题与修复

个人资料页打开左下角或右上角账号菜单时，正文向右移动，关闭后复位。当前用户 Chrome 中两处均可稳定复现：滚动条宽度为 11 CSS px，标题和表单右移 5.5 CSS px。

共享基础样式将 `body` 设置为 `width: 100%`。Radix 菜单打开时隐藏页面滚动条，并通过右侧 margin 补偿滚动条宽度，但固定百分比宽度使 body 仍从 1709 px 扩大至 1720 px，居中内容因此移动。

在 `packages/ts/ui/src/styles/base.css` 移除 body 的 `w-full`，恢复自动宽度，让滚动锁补偿正确参与布局；加入注释说明原因。保留已有的 `position: relative` 及菜单交互。沿用 React、Radix 和 Tailwind CSS；本轮只调整共享 CSS，无新增依赖或数据库变更。
