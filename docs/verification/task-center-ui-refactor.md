## 实现与边界

- React、TypeScript 和现有 shadcn/ui 组件构建列表、筛选栏、状态标记、菜单、分页与 Drawer；TanStack Table 负责列模型和显隐，TanStack Query 负责查询和轮询。
- 搜索、状态、工作空间、时间、多类型筛选及提交时间升降序在 Go API 中执行。排序与规范化的类型集合绑定签名游标，保留实时授权、候选预算和来源不可用错误。搜索先按目录定义的任务标题或任务/来源编号前缀缩小数据库候选，再逐项核验来源资格，避免按编号查询仍扫描全部任务。无数据库迁移。
- 列表默认每页 10 条。分页显示实际本页数量；API 不提供精确总页数，因此不伪造总量或末页。前后页路径保存在浏览器历史状态，刷新及浏览器后退保留位置；从外部直接打开续页可以回到首页。
- 任务继续在原业务页面创建。结果跳转再次请求后端核验；取消和重试使用后端能力、固定执行代次与控制版本。理由和请求编号在未知提交结果时冻结，重放原请求核实。
- 历史执行、事件、工作进程尝试、业务变更记录、关联任务、旧通知和旧监测任务深链继续可用。长整数字符串不转成 JavaScript Number。
- 来源错误或权限变化时隐藏无法核实的缓存行与详情。管理摘要资格不代表结果读取资格。
- 内部运行概况按需加载；不为装饰性计数追加全范围查询。

## 验收步骤

1. 打开 `/tasks`。应看到紧凑表格及“我的任务 / 管理视图”；账户菜单没有“任务中心”，顶部仍有“任务”。
2. 搜索任务名称/编号，选择状态、多个任务类型、工作空间和时间。翻页后仍满足筛选；点击提交时间改变整组排序；重置恢复筛选。
3. 隐藏/显示列，改变每页数量，前后翻页、刷新和浏览器后退。表格不重复任务，筛选或排序变化回到首页。
4. 打开任务。应出现系统带遮罩 Drawer；按 Escape、点击遮罩或关闭按钮可关闭，焦点回到任务按钮；手机显示底部抽屉。
5. 查看结果与原业务详情。成功结果应打开对应真实业务对象；结果过期、不可用或受限应明确显示。
6. 在有权限的失败任务上输入理由并确认重试。应产生新执行代次，旧记录仍可查看。取消操作需确认；只显示后端允许的操作。
7. 查看管理视图和运行概况。仅展示当前获准范围；无结果读取资格时禁用结果和原业务按钮。
8. 检查深色、375px 手机宽度、200% 页面缩放，无页面横向溢出，菜单和抽屉可键盘操作。
