## 人工验收步骤

1. 刷新本地入口，确认侧栏只有“派生监测”，两个标签都可进入。监测通道首屏应能看到现有三条通道，结果仍为 `0.000890`、`2.799133`、`-0.210000`，单位与数据状态明确。
2. 打开通道详情，依次查看四个视图。应能查看完整覆盖、真实输入、历史与运行管理；关闭后返回原目录和筛选。详情应为系统遮罩 Drawer，键盘 Escape 可关闭并返回触发入口。
3. 在指标定义中查看已发布版本，选择“基于此版本编辑”。应进入完整分步编辑区；输入要求可在 Drawer 中配置，切换步骤不会丢值。可取消未保存编辑并继续原表单。
4. 新建一条验收用定义：填写业务信息、输入单位和计算规则，保存后校验，再填写发布原因并发布。应显示真实校验结果与版本；不合格字段应能从错误提示直接定位。
5. 使用发布的版本创建验收用通道。选择所属对象、兼容输入和参数；保存后先试算、再预览启用影响并确认。自动起点、试算范围和历史回算范围均由用户明确选择。
6. 在新建通道时进入“新建规则并返回”，完成规则后返回。原通道名称、编码与所属对象应保留，刚发布的版本应已选定。
7. 在项目中查看同一入口。指标维护由租户负责；未获准完整输入时应显示受限提示；归档项目应保持可读且无新建、发布、控制等写入入口。
8. 在窄屏及深色主题下检查目录、输入 Drawer、版本操作与固定操作栏，确认可读、可点、无横向页面溢出。
