日期：2026-11-15

## 目标与实现

将项目成员管理统一到平台「账号管理」的布局和交互：PageHeader、状态标签页、紧凑表格、搜索与重置、显示列、游标分页、行内操作菜单、系统遮罩 Drawer。复用 React / TypeScript、Tailwind 和 `@infrapro/ui` 的现有组件及主题，不引入依赖。

列表通过原有项目成员 API 按搜索、状态和每页条数查询，默认每页 10 位成员。列包括成员账号、成员状态、项目身份、账号 / 租户状态、加入时间和操作。项目成员列表接口没有返回绑定角色；真实角色、有效权限和来源、授权历史在详情中读取，避免逐行请求授权详情。

成员详情、添加、配置角色、暂停、恢复及移除均在 Drawer 中完成。桌面从右侧打开，窄屏从底部打开，关闭后保留筛选与页码并恢复焦点。原 `/members/:membershipId` 链接仍可打开对应详情，关闭后返回成员列表。

继续沿用项目变更预览、操作原因、版本冲突、密码复验及请求幂等流程；保留本人和当前管理员保护、已结束关系只读、项目归档限制及授权读取边界。后端接口、权限规则和数据库结构不变。

## 实现入口

- `apps/console/src/features/projects/members-page.tsx`：列表、筛选、分页和详情链接兼容。
- `member-ui.tsx`、`member-operations.ts`：状态、菜单和操作条件。
- `member-panel.tsx`：成员详情、添加及现有变更表单集成。
- `member-authorization.tsx`：角色、有效权限和授权历史。
- `tests/e2e/project-members-page.spec.ts`：真实 API 和浏览器回归。
