## 设计与范围

2026-11-15 用户选择原型 A，并要求平台、租户、项目三个层面一起正式重构，保留现有功能。三个入口共用 `AuditWorkspace`，采用紧凑表格、横向常用筛选、更多筛选抽屉、操作记录/导出任务导航和带遮罩的详情抽屉。

- 平台：`/access/audit`，标题“平台审计”。
- 租户：`/t/$tenantId/audit`，标题“租户操作记录”。
- 项目：`/t/$tenantId/p/$projectId/audit`，标题“项目操作记录”；保留项目上下文和切换项目入口。

React / TypeScript 负责交互，TanStack Router 保存筛选、详情深链和游标历史，TanStack Query 负责真实查询、导出轮询及缓存失效。使用现有 Tailwind、共享 Table/Button/Tabs 和 `ResponsivePanel → Drawer`；桌面右侧抽屉、手机底部抽屉，复用系统遮罩、键盘关闭和焦点恢复。Go 审计 API、数据库、对象存储与任务契约沿用现有实现，没有新增接口或数据库迁移。

正式页面没有原型方案切换器、模拟数据或模拟导出。原型源文件和视觉证据归档到 `.artifacts/audit-ui/prototype/audit-prototype-approved-a.tar.gz`；遵循项目约定，在当前 checkout/分支实现，没有创建分支或 worktree。

| 权限与异常 | 平台/租户/项目边界、成员资格、授权修订、账号切换的缓存清理保持原有逻辑。来源错误时隐藏不能核实的记录；保留部分覆盖、游标失效、查询预算和重试提示。 |
