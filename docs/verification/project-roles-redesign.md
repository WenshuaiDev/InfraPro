## 人工验收步骤与预期

1. 打开项目角色：应显示统一表格，侧栏没有“项目权限目录”。切换自定义／预置、搜索与状态筛选，结果及分页应正确。
2. 打开“验收·项目资料维护”：应出现遮罩 Drawer，默认显示中文权限，编码默认隐藏；可查看绑定成员、基本资料和操作历史。关闭后回到原列表位置。
3. 点击配置权限：应能按业务搜索与分组；管理员保留能力不可勾选。修改选择后预览，应展示角色权限增减及真实成员影响。此步骤可取消，取消后现有角色不变。
4. 新建一个临时验收角色，配置查看项目资料并填写原因：保存后刷新仍存在，且绑定人数为 0。可编辑说明、复制为独立角色；停用、启用和删除均需预览与原因。
5. 对有绑定的角色尝试删除预览：应说明仍有当前绑定并禁止确认。项目管理员角色应没有编辑、复制或直接删除入口。
6. 访问旧权限目录链接：应进入项目角色页。检查窄屏和深色主题，并在菜单／详情中分别按 Esc，确认关闭层级和焦点正确。
