## 用户验收

1. 在平台租户完整档案或列表编辑面板填入名称和原因，临时阻断详情读取，再恢复：输入保留，故障时不能提交，重新读取后可主动保存；确认无权读取后表单消失。
2. 由受邀者接受测试邀请，再暂停或移除该成员；平台修改租户名称、编号或停用说明。受邀者重看旧邀请应只看到原接受快照和成员结果。
3. 在设施数值属性中逐键输入 `0.05`、`-0.5`、`1.05`、`1.00`，保存并重新打开；数值应一致。输入 `1e` 保存应报错且保留输入。
4. 编辑已有测点，展开构件树、切换归属：面板保持打开、服务端尚未变化；点击保存后才改变归属。
5. 新建并删除测试通道，用只有资源查看权限的账号展开设施变更记录：仍可读到固定指标名称、版本、枚举含义和单位；停用定义不影响历史解释。
6. 通过部署入口保存超过 16 KiB 的合法工程定义和资源属性；应成功。超出定义内容或资源总请求上限仍应失败。
