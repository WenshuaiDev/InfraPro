## API 与统一运维 CLI 拆分

2026-11-09 按用户追加要求完成，状态：**Awaiting acceptance（待用户验收）**。统一 CLI 名称为 **`infrapro`**。

- `services/api` 仅保留 HTTP 服务；`tools/infrapro` 是独立项目运维 Go module，当前提供 `database` 与 `account` 命令组。
- 账号业务、项目配置、迁移与依赖装配移至独立 `packages/go/platform`；foundation 继续提供通用基础能力。API、CLI 互不依赖。
- API 与 CLI 镜像分开构建，Compose 通过 `ops` 服务按需运行 CLI；`pnpm infrapro ...` 为本地统一调用入口。
- 独立模块构建及依赖图检查通过，CLI 不导入 API 或 Gin；无配置帮助、无效参数处理、仅数据库配置的真实迁移均通过。
- 迁移版本和 SQL 内容未修改；没有重建本地或正式账号数据。方案及进一步验收步骤见 [后端工程调整记录](../requirements/backend-organization-plan.md)。
