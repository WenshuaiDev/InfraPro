## 功能验证

| 场景 | 结果 |
| --- | --- |
| 指标编制与发布 | 在浏览器中关联毫米、厘米，将厘米设为标准后保存草稿。校验、发布、样例试填及目录返回均通过。桌面和手机均通过。 |
| 通道采用 | 新通道默认选中厘米，可更改为毫米并保存。切换到枚举时单位清空。同类别但未授权的米不在候选中，直接调用写接口返回 422。 |
| 固定版本与历史 | 在隔离数据库为同一指标发布两版并创建通道。新版移除厘米后，新版拒绝厘米，旧通道仍返回原指标版本和厘米版本。 |
| 模板、设备与派生 | 模板绑定默认选择指标的标准单位。设备资源和项目通道的既有流程通过回归。选择公共指标的派生输入仅显示其允许单位，服务端拒绝在目录单位上额外施加幂次。解析服务使用真实测试进程完成回归。 |
| 文件导入 | 使用独立 PostgreSQL、对象存储及 ClickHouse 验证。错误映射在保存时被拒绝。单位列与通道不符的文件进入待处理状态。匹配的 12.5 mm 入库并读回为十进制 12.500000000000。枚举空单位与数值缺失单位另有回归覆盖。 |
| 查询比较 | 相同固定单位可以共用绝对值轴。同符号不同版本、同基础单位不同时间幂次分别使用各自的轴。 |
