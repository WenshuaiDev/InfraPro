# 平台与租户角色界面重设计验证

日期：2026-11-10。状态：**Awaiting acceptance**。本记录只覆盖[本轮界面方案](../requirements/role-management-redesign.md)，自验与人工验收分别记录；尚未获得用户人工验收。

随后追加的角色及其他表格列宽优化，单独记录在[表格列宽优化验证](table-layout.md)。

## 交付范围

- 平台角色、预置租户角色、预置项目角色按标签显示统一表格；租户角色使用相同搜索、筛选、行菜单、显示列和分页交互。
- 每页 10／20／50 条，使用真实接口游标，支持第一页、上一页、下一页；筛选或每页数量变化回到第一页。不显示接口未提供的总条数或总页数。
- 平台、租户及平台预置角色面板均使用 shadcn/ui Base UI Drawer。桌面右侧 560px 宽、12px 边缘留白和圆角，遮罩使用 8px 背景模糊；375px 手机使用底部 Drawer。详情与编辑共用一个面板，租户详情保留深链接，关闭保留列表条件与页码。
- 详情按权限、资料及可访问的成员／记录分标签；权限编码使用 Switch，编辑时可用 Toggle 仅看已选。角色状态仍通过确认表单变更。
- 权限详情与配置页共用分组规则，显示组名、数量、用途、范围与风险。租户按资料、项目、成员、邀请、审计展示，管理员保留能力单独成组；没有目录说明的历史编码保留展示，不丢失。
- 保留原因、密码复验、版本冲突、租户授权影响预览、管理员保留权限及即时撤权。后端 API、权限定义、数据存储和迁移未因本轮设计改变。
- 修复表格刷新替换按钮后关闭面板无法归还焦点的问题，包括 Base UI 关闭清理与列表重新渲染的时序；给租户角色链接及主导航显式指定主题文字颜色，避免切换深色主题后链接继承颜色的显示问题。

## 启动及人工验收

本机已有环境使用原账号直接访问 [平台角色](http://127.0.0.1:5173/access/roles)。服务停止时在仓库根目录执行 `make dev`；不重复 bootstrap，不需要数据库迁移。租户角色从工作空间切换器进入对应租户后选择“租户角色”。

1. 在平台切换三个角色标签：每次只出现当前范围的表格，预置角色可查看但不能编辑。
2. 搜索角色，切换状态或来源；有多页时翻页并改变每页数量：结果正确，条件变化回到第一页。关闭详情后仍在原列表位置与筛选条件。
3. 打开一个自定义角色：桌面显示有圆角及边缘留白的右侧抽屉，外部页面变暗并模糊，抽屉内容保持清晰。权限按与配置页一致的分组展示，组名和数量可见；行末菜单及面板内按钮可进入对应操作。内置角色只读。
4. 核对详情各组权限及总数，打开“显示权限编码”；在权限编辑中搜索、切换“仅看已选”：选择不丢失。租户管理员保留能力单独展示且不可配置。使用验收角色填写原因并保存，租户变更仍先预览影响。
5. 进入租户角色详情，切换权限、资料、绑定成员和操作记录；复制详情 URL 重新打开，仍进入同一角色。点击关闭后回到列表。
6. 切换深色主题，用 375px 手机宽度打开同一角色：名称和说明清晰，底部抽屉内可滚动，表单操作可达，没有整页横向滚动；使用键盘关闭后焦点回到触发位置。
