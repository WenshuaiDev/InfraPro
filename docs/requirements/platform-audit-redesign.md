# 平台审计可读性重设计

日期：2026-11-10。状态：**Awaiting acceptance**。用户要求复用角色权限优化方案的组件，并重新考虑每行字段的用途。实现与自验完成，等待用户人工验收。

## 目标与范围

平台审计回答“谁在什么时候，对什么做了什么、结果如何”。只调整平台审计页面及其读取接口；租户／项目工作空间的审计界面保持现有范围。

- 主表：发生时间、操作（中文名称及变化摘要）、操作者（显示名称及用户名）、影响对象（对象类型及名称）、真实结果、查看详情。原因作为可选列；内部 ID、英文事件码及原始 JSON 不占据主表。
- 分类：全部记录、管理变更、登录与安全、系统维护。搜索名称／用户名／原因，提供结果、具体操作、时间及高级精确 ID 筛选；服务端筛选全部记录。
- 与角色页一致的 Table、Dropdown Menu、Tabs、Select、Pagination、Switch 和 ResponsivePanel。桌面右侧 Drawer，手机底部 Drawer；保留筛选与页码，关闭恢复焦点。
- 详情先说明操作、结果、原因及有业务意义的前后变化。技术信息集中提供记录／请求／对象 ID、来源地址、客户端信息和原始内容，供排查问题使用。
- 名称优先取历史快照；无快照时用当前对象名称并在详情标明，无法解析的历史记录明确标注。失败登录不冒充已认证的操作者；无差异的登录事件不显示空 JSON 作为“变更”。

## 技术与数据流

- React／TypeScript 负责事件文案、受控差异展示、筛选及抽屉；TanStack Table 渲染语义表格，TanStack Query 复用角色列表的游标分页状态。
- shadcn/ui 与现有 Base UI Drawer 负责菜单、标签、分页、焦点、遮罩、深浅主题和移动适配，不新增 UI 依赖。
- Go／pgx 在原平台审计权限及租户可见性条件内读取 PostgreSQL 事件、真实 outcome 和对象名称；增加只读展示投影及分类／结果过滤，保留原始事件详情。不改写旧记录、不新增数据库迁移。
- 按 `(created_at DESC, id DESC)` 稳定分页，返回不透明游标；不伪造总数。兼容原数字游标，通过原记录时间定位。
- OpenAPI 和 TypeScript 客户端同步新增字段；项目共用的事件类型保留兼容。名称与权限解释不依赖调用者额外拥有账号／角色目录读取权限。

## 人工验收

1. 刷新平台审计：主表使用中文事件、名称和真实结果；时间从新到旧，行内没有 UUID／校验和／JSON。
2. 查看权限配置：摘要说明新增／移除项数，详情列出权限名称；角色／租户资料变化按字段展示前后值。
3. 查看登录、失败登录和同步记录：分别说明认证结果或同步内容；没有快照的记录明确说明边界。
4. 分类、搜索、筛选、重置和每页条数作用于完整查询；改变条件回到第一页，翻页不重不漏。
5. 打开／关闭详情保留列表条件与页码，关闭恢复焦点；技术信息可按需查看。
6. 桌面／375px 手机、明暗主题可用，无整页横向溢出；空态、错误、重试和非法时间范围提示清晰。
