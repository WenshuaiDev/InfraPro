# 普通附件在线预览

状态：Awaiting acceptance（2026-11-15，含附件预览与版本记录合并）。用户已要求实施，自验通过；人工接受单独记录。自验与整站检查结果见[验证记录](../verification/document-preview.md)。

## 目标与范围

为现有普通附件 PDF、DOCX、XLSX、CSV、TXT 增加只读在线阅读。租户、项目资料页、文件工作区及历史修订共用阅读器，已有附件直接生效。PNG/JPEG 保持服务器生成的安全图片预览。Word/Excel 指当前允许上传的 DOCX/XLSX；旧二进制 DOC/XLS、PPTX 不在此次格式扩展内。

| 格式 | 阅读操作 |
| --- | --- |
| PDF | 连续多页阅读、前后翻页、页码跳转、文字选择/复制、全文搜索与命中跳转、缩放、适合宽度、旋转、全屏 |
| DOCX | 段落/标题/列表/图片/表格/页眉页脚阅读，按文档显式分页浏览、翻页/跳页、搜索、缩放、适合宽度、全屏 |
| XLSX | 工作表切换、行列标识、冻结表头、分页、全文单元格搜索、选中单元格的值/公式查看、缩放、全屏 |
| CSV | 引号/换行/分隔符解析、编码选择、表格分页、搜索、行列标识、单元格查看、缩放、全屏 |
| TXT | 行号、分页、搜索/命中定位、UTF-8/UTF-16/GB18030 编码选择、自动换行、字号缩放、全屏 |

## 设计与技术

- React/TypeScript 复用现有附件详情和 UI 组件，阅读器按格式延迟加载。长表格/文本分页，解析在可终止 Web Worker 中运行；解析超时和超限明确提示并保留下载。
- 附件详情使用单一阅读界面，取消概览/版本记录页签及独立历史入口。预览上方的版本选择器展示版本号、时间、原因及当前版本标识，选择后正文与原件下载同步切换；历史版本旁可返回最新版或还原为新版本。使用现有 DropdownMenu 的键盘交互和版本游标接口，展开时加载历史，固定历史链接仍自动跨页定位；加载更多失败保留已加载记录并允许重试。
- PDF.js 本地打包，按可见页渲染，文字层提供选择与搜索；字体、CMap、WASM 资源随部署发布，不依赖外部预览服务。
- docx-preview 在独立不透明来源的 sandbox iframe 中运行。CSP 禁止网络、外部框架、表单，关闭 altChunk、链接导航和文档脚本，父子窗口只交换有限阅读指令和状态。Word 自动分页与桌面 Office 可能不同，不声称像素级一致。
- SheetJS 解析 XLSX 已保存的单元格值和公式文本；不计算公式、不执行宏、不读取外部数据。Papa Parse 解析 CSV，所有单元格及 TXT 以 React 文本节点呈现。
- 现有 Go 读取网关、PostgreSQL 元数据和私有 S3 正文不变；新增客户端二进制读取方法调用当前受控 content 路由，仍逐块授权、完整性校验和审计。文档不作为管理站点可执行 HTML 提供，无新数据库迁移或转换后台任务。
- 读取前核对当前空间、账号、正文下载资格和指定修订。退出、切换空间/账号/修订、权限失败时卸载阅读器，终止请求/Worker、释放对象 URL 和内存。不将正文写入持久缓存。
- 在线读取上限沿用普通附件 100 MiB；解析时额外限制展开量、表格单元格及文档规模，超限明确显示边界而不静默冒充完整内容。

## 验收

使用真实三页 PDF、含图片表格及分页的 DOCX、两个工作表且含日期/公式/合并单元格的 XLSX、带中文/逗号/引号/换行的 CSV 和多编码 TXT 验证上述操作。检查旧附件与历史修订、不同权限、撤权、切换账号、损坏/加密/超限文件、窄屏/深色/键盘/全屏退出。浏览器不能出现运行时异常或文档触发的外部请求。原件下载摘要不变。

合并界面验收：没有概览/版本记录页签；在预览上方直接选版本，正文、版本说明、下载及还原对象一致；版本分页、失败重试、旧版本直达链接、返回最新版、键盘选择与 Esc 返回、375px 窄屏均可用。

技术依据：[PDF.js](https://mozilla.github.io/pdf.js/examples/)、[docx-preview](https://github.com/VolodymyrBaydalka/docxjs)、[SheetJS](https://docs.sheetjs.com/docs/getting-started/installation/nodejs/)、[Papa Parse](https://www.papaparse.com/docs)。
