# 工程配置与资源页面改造

日期：2026-11-11。状态：**Accepted**。实现与自验完成；用户于 2026-11-11 明确回复“没问题”，要求提交并推送主分支，无需再次验收或测试。

## 已确认的页面方向

沿用左侧菜单和现有工作空间切换。各目录采用列表进入独立详情，详情按内容分标签。列表的搜索、筛选、分页、显示列及行操作沿用角色管理页的组件和视觉规范。页面不增加流程图、关系图、任务导览或步骤条。

平台维护设施类型、指标、单位和公共监测模板。租户保留设施管理、项目资源授权、本租户监测模板，移除四个重复公共目录。公共设施类型、指标、单位在新建资源和编制模板时选择；本租户模板目录提供“从公共模板复制”的选择面板。项目继续按项目权限读取可用公共选项，不新增公共目录。

原型来源：`codex/prototype-engineering-workspaces` 分支的 `92da5ca`，`apps/console/src/features/engineering/prototype/README.md`。本次采用 A 的列表与详情布局，并按用户最新要求移除租户公共目录。正式实现继续使用真实接口，不引入模拟状态或原型切换条。

## 页面与交互

| 范围 | 页面 | 内容组织 |
| --- | --- | --- |
| 平台 | 四个定义目录 | 搜索、状态筛选、分页、名称链接、行操作；新建抽屉；类别管理按需打开 |
| 平台 / 租户模板 | 定义详情 | 基本资料；类型的属性字段与构件规则、指标取值规则、模板适用范围与监测项；样例预览；版本记录；操作记录 |
| 租户 / 项目 | 设施目录 | 搜索、类型和状态筛选、分页；新建抽屉；进入设施详情 |
| 租户 / 项目 | 设施详情 | 基本资料、构件、测点、业务通道、变更记录；租户可查看项目使用；下级对象单独显示详情并返回来源列表 |
| 租户 | 项目资源授权 | 项目列表；项目详情按设施范围、新建政策、操作记录分标签；通过设施选择面板添加范围 |

已发布定义以资料与表格展示，不以禁用表单或原始 JSON 作为主要内容。编辑仍针对草稿；保留校验、直接发布、版本停用恢复、复制、版本比较和审计能力。输入变更原因后执行写入，保留已有影响确认、请求回执、并发修订、权限及范围隔离机制。

设施、构件、测点、通道保持现有所有权和授权边界。通道接口按测点读取，因此业务通道标签提供测点选择，再显示对应通道列表，不伪造设施级聚合结果。项目仅有下级对象权限时保留最小定位信息。

## 技术与实施

- TypeScript / React：重组现有页面与展示组件，继续使用真实 API client。
- shadcn UI / Tailwind：复用 Table、Input、Button、DropdownMenu、Tabs、ResponsivePanel、ListFilter、ListPagination，保持角色管理页的一致性。
- TanStack Router：保留定义 ID 和设施内部选择的深链接，增加内容标签；旧公共目录地址转向实际使用入口。
- TanStack Query：沿用账户、租户成员、项目授权版本的缓存隔离，以及列表游标与详情刷新。React Hook Form 保留未保存输入。
- 后端与数据库：使用现有 Go API 和存储，不迁移、不修改资源归属、发布或授权业务规则。

分小步实施：目录与导航 → 定义详情 → 设施详情 → 项目授权 → 类型检查、静态检查与相关桌面/窄屏浏览器用例。

## 人工验收

1. 平台四个目录使用一致的搜索、筛选和分页；名称进入独立详情，返回目录保留当前筛选。
2. 类型字段、构件规则、指标规则与模板监测项能在相应标签直接查看；草稿可编辑、保存、校验、发布，发布版本只读。
3. 租户和项目侧栏没有重复公共目录；创建资源、选择指标和编制模板时仍可检索公共选项及明确版本。
4. 本租户监测模板可选择公共模板版本并复制成独立草稿。
5. 设施的构件、测点和通道分开浏览，点击对象进入其详情，返回位置明确；刷新保留当前对象与标签。
6. 项目授权的设施范围、新建政策和操作记录分开浏览；项目端遵守实际授权，不扩大可见数据或可写操作。
7. 桌面与窄屏无整页横向溢出，弹窗可键盘操作并恢复焦点；失败、冲突和响应丢失时输入仍保留。
