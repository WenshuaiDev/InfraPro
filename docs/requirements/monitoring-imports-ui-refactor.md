## 正式实现

- 列表检索文件名或批次编号，状态与文件类型支持多选；服务端按导入时间正序/倒序及 ID 稳定分页，返回当前真实页，不虚构总页数。搜索和筛选作用于完整授权范围，部分可见批次只按可见名称/编号匹配，不通过隐藏原文件名或类型泄露信息。
- 在租户及项目导入路由下挂载嵌套 Drawer 路由，保留现有批次 URL。筛选、页大小、游标和详情页签保存在 URL，关闭详情保留列表条件；前进/后退可恢复页面状态。
- 复用已有上传/续传、映射编辑、重复集合核对、校验、发布、取消、撤销影响预览、重新采用与文件访问接口。写操作提交真实原因和修订号；重试相同内容复用 request_id，处理中防止重复提交。操作成功刷新列表、详情及关联记录。
- Drawer 保留可疑值和错误的不同语义、全部校验计数及原始文件信息。问题报告分页读取；处理记录接入审计能力和事件查询，并保留关联任务入口。
- 保持租户/项目授权隔离、部分数据裁剪、归档项目只读以及源文件/撤销独立权限。读取失败或权限变化时不显示陈旧详情及可用写操作。
- 保留键盘操作、关闭后的焦点恢复、独立滚动、窄屏适配、深浅主题、载入/空/错误状态。

## 技术与数据流

- React、TypeScript、Tailwind 和项目已有 shadcn/ui：实现 A 表格和 Drawer，复用系统视觉与无障碍组件。
- TanStack Router：列表父路由与批次子路由、URL 查询状态；TanStack Query：读取、失效刷新和任务状态轮询；TanStack Table：服务端分页/排序下的表格、列显隐和选择。
- Go + PostgreSQL：扩展导入列表过滤和稳定游标，复用现有身份/资源授权及项目范围裁剪。现有 ClickHouse / 对象存储仍承担监测数据和原始文件，导入和采用业务规则不变。
- OpenAPI 与 TypeScript API client 同步查询参数。Go 集成检查、客户端检查、Playwright 浏览器验证覆盖真实接口及关键权限场景，写入验证使用独立合成数据。

## 验收条件

1. 默认导入页面呈现 A 方案，无原型切换栏；文件名、状态、质量摘要和数量可快速扫读。
2. 搜索能查到后续页批次，多选筛选、每页数量、导入时间排序和上一页/下一页正常，条件切换回到有效首页。
3. 文件名或菜单打开当前 Drawer；四个页签显示真实内容，长报告可翻页。详情直链、刷新、前进/后退和关闭均保留正确上下文。
4. 从实际文件上传到映射、校验、发布的路径可完成；错误阻断、重复核对、无新增完成、失败重试、取消、撤销和重新采用保持原业务语义。
5. 无源文件权限不提供下载；无管理/撤销权限或归档状态不提供相关写操作；部分可见批次不显示完整统计、映射、源文件或审计信息。
6. 网络/服务错误有明确反馈，重试不会重复提交相同命令；权限变化后旧数据和旧操作被隐藏。
7. 桌面、375px 窄屏、键盘和深色主题自查通过。完成后记录为 Awaiting acceptance，用户手工确认前不标记 Accepted。
