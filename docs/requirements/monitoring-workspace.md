# 监测数据查阅工作空间

状态：Awaiting acceptance。2026-11-12，用户确认第二版原型，并要求将主导航改为单击通道、把多通道比较放入独立遮罩抽屉。实现及本次自验已完成，待用户人工验收；未标记 Accepted。

## 范围与交互

- 沿用管理端 PageHeader、资源目录和 shadcn/ui 设计。左侧设施—构件—测点—通道树按层加载，通道单击即查看，无复选框。测点／通道深链接及浏览器前进后退继续有效。
- 主工作区只查阅一个通道：最新在用观测的精确值、单位、质量、观测时间与读取时间常驻显示；下方为紧凑时间工具条、趋势／原始明细。默认质量为正常及未标注，最新值不受历史时间与质量筛选影响。
- 最新值每 30 秒刷新，可暂停或立即刷新。历史视窗保持固定，回到最新后跟随最新覆盖。失败明确显示旧结果与更新时间，不伪装为实时成功。
- 多通道比较使用右侧大抽屉，桌面最大 86rem，四周留出遮罩；窄屏改为底部 92dvh 抽屉。在抽屉内选择比较通道，兼容通道在同图展示；不同指标、单位、方向、基准或时间含义继续分组。关闭不改变主页面当前通道与时间范围。
- 数据概况使用中等宽度右侧抽屉，区分当前查阅范围与所选通道全历史；按范围／样本、逐通道统计、质量分布展示，发布／在用／撤销口径折叠说明。日历统计、精确值、历史权限、导出与错误重试继续保留。
- 页头“工作空间统计”按需读取全部获准通道的总览，保留原页面累计发布、在用、质量样本和覆盖时间；它与选中通道的数据概况明确区分，均不常驻占用页面。
- 生产页面不再使用开发原型切换入口。导入、批次和任务功能保持可达。

## 技术与数据流

使用现有 React / TypeScript、TanStack Router / Query、Tailwind 语义色和 `@infrapro/ui` 的 shadcn/ui 组件；ResponsivePanel 扩展可选宽度以复用现有 Drawer 遮罩、焦点恢复、移动端行为。ECharts 继续负责时间轴、同图曲线与精确值提示；原始观测与摘要保持区别，已知断点不跨越，空值不补零。

租户目录复用设施构件树接口及带祖先的搜索结果；项目目录使用项目范围资源接口，分别分页读取构件和所属测点，避免访问租户树。项目搜索目前按设施名称／编号，输入框明确标注“搜索项目设施”。每张图最多 6 条兼容曲线，可切换曲线页；比较选择最多 50 个通道。

沿用后端 selection / immutable snapshot / latest / overview / statistics / trends / details 接口，不迁移数据库、不改观测或授权口径。实时最新值独立查询；趋势、明细、概况与导出共享当前查询快照。查询继续带工作空间身份与权限版本，切换通道或撤权时取消旧请求，禁止将旧通道结果冒充新通道结果。

## 验收

1. 展开设施、构件和测点，单击通道后显示该通道最新值与趋势，主树没有勾选框；深链接与前进后退匹配。
2. 最新值有明确观测时间及质量；调整历史窗口不会改变最新值口径，自动更新不会把历史视窗拉回。
3. 比较抽屉有遮罩，支持增加／移除通道与同图图例开关；关闭后主页面选择和窗口不变。
4. 数据概况不占主页面空间；时间和质量口径明确，枚举、大整数、高精度小数与空样本不被误算。
5. 键盘可选树节点及操作抽屉，Esc 关闭且焦点返回触发按钮；桌面、窄屏和明暗主题布局可用。

自验结果记录在 `docs/verification/monitoring-workspace.md`；通过后进入 Awaiting acceptance，用户明确验收后才标记 Accepted。
