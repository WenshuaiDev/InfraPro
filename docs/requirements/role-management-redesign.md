# 平台与租户角色管理界面重设计

日期：2026-11-10。状态：**Awaiting acceptance**。用户要求参照 shadcn-admin Tasks 页面，并使用 shadcn/ui 的抽屉、菜单、分页、标签及开关组件重新设计。此前权限说明整合继续有效，独立权限目录菜单不恢复。包含追加的 Base UI Drawer 与权限分组调整；自验通过，等待用户人工验收。

## 目标与范围

- 平台角色页以“平台角色／预置租户角色／预置项目角色”标签切换，统一为紧凑表格，消除纵向堆叠卡片。
- 租户角色页采用相同表格、搜索、来源和状态筛选。每行显示角色名称与说明、来源、状态、权限数、绑定人数及操作菜单。
- 桌面详情和编辑使用右侧 Drawer，带圆角、边缘留白与背景模糊；手机使用底部 Drawer。详情分开权限、基本资料，以及有权查看的成员和操作记录。保留可分享的租户角色详情 URL。
- 新建、编辑、配置权限、启停和删除沿用真实 API、变更原因、版本校验、权限范围与影响预览。预置角色只读，普通租户预置角色可在租户内复制。
- 权限详情与配置页采用相同分组，显示组名、数量及用途；租户管理员保留能力单独分组。权限编码用 Switch 按需展示，Toggle 提供“仅看已选”；角色状态操作仍须确认。
- 本轮修改平台与租户角色界面，以及平台内预置项目角色的展示；项目工作空间自身的角色流程不在本轮范围。

## 技术与数据流

- React／TypeScript 实现页面和共享角色列表；TanStack Table 驱动列及表格渲染，现有 TanStack Query 管理服务端查询与缓存。
- shadcn/ui Base UI Drawer 使用 `@base-ui/react` 1.9.0，负责滑入、模态遮罩、焦点和滚动管理；沿用现有 Radix Dropdown Menu、Tabs、Select、Checkbox、Switch、Toggle，Pagination 提供分页结构。移除不再使用的 Vaul 依赖。
- TanStack Router 保留租户角色深链接；列表作为父路由，详情作为侧面板子路由，关闭后回到原列表。
- 现有角色 API 返回游标及下一页，不提供总数。分页保留前页游标和缓存，提供每页数量、前后翻页及已访问页，不伪造总页数；筛选或页大小变化回到第一页。
- Go、PostgreSQL、Redis、权限目录与鉴权契约保持原实现；新界面从现有 API 读取角色和权限，保存继续调用原接口。

## 人工验收标准

1. 平台页一次只显示选定范围的表格；预置角色不再在页面下方堆叠。
2. 平台和租户页可搜索、筛选、重置及翻页；空结果、错误和加载状态清晰，换条件回到第一页。
3. 点击角色或行菜单，在桌面打开右侧 Drawer，在 375px 手机上打开底部 Drawer；背景模糊、面板内容保持清晰，关闭后回到原列表和合理的焦点位置。
4. 权限、成员、记录可以按标签切换；权限说明、编码开关、仅看已选均正常，管理员保留能力不可选。
5. 新建、编辑、复制、权限保存、状态变更和删除完成原有确认流程；预置角色限制、停用和撤权即时效果保持。
6. 桌面、手机及深浅主题可用，无整页横向溢出；键盘可操作菜单、标签、分页和面板，登录后的租户角色深链接仍有效。

## 2026-11-10 追加调整：Drawer 与权限分组

按用户新截图，平台、租户及平台预置角色的全部角色面板改用 shadcn/ui Base UI Drawer。桌面从右侧滑入，采用浮起的圆角边框及 12px 边缘留白，背景遮罩增加模糊；手机保留底部方向。权限详情沿用配置页分组规则显示标题、数量、用途、范围及风险，租户管理员保留能力单独分组。编码开关、深链接、焦点恢复和原有授权规则保留。只迁移 Drawer 到 @base-ui/react，其余现有组件继续使用既有实现。验收重点：右侧抽屉及模糊遮罩、分组数量和内容、键盘/行菜单/滚动及权限变更闭环。
