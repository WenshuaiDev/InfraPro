## 启动与保留

服务运行时直接访问上述入口。如果停止或电脑重启，在仓库根目录执行：

```bash
docker compose --env-file .env -f deploy/compose/local.yaml up -d --wait
node scripts/acceptance/start.mjs
```

这是独立验收环境；`make dev` 的 `127.0.0.1:5173` 使用普通开发库。验收请使用 `localhost:25173`。停止服务只关闭进程，保留全部数据。

Go 代码更新后，先停止验收服务，执行 `node scripts/acceptance/setup.mjs` 更新构建/迁移，再启动。已有环境不会重建账号或重置密码。

维护及自验命令：

```bash
node scripts/acceptance/ops.mjs access check
node scripts/acceptance/verify.mjs
```

首次生成数据时，`seed.mjs` 会自动完成单账号配置。已经完成的环境再次运行 seed 会直接退出，保留用户的操作；如需重新执行明确的账号归并，可运行 `node scripts/acceptance/single-account.mjs`。配置只调用现有角色及管理员交接 API，审计可查。
