## 启动与资料位置

在仓库根目录执行：

```bash
pnpm local:start
pnpm local:status
pnpm local:restart
pnpm local:stop
```

`local:stop` 停止本机应用进程，持久化数据和 Docker 基础设施保留。`local:start` 检查存储就绪后启动服务；当前已纳入独立解析服务、设备接入中继和接入工作进程，并检查解析服务的认证就绪接口。不要对已有数据再次执行账号 bootstrap 或清空数据库。

当前运行 16 个本机应用进程、8 个项目 Docker 容器。解析服务为 `127.0.0.1:28091`；中继控制口为 `127.0.0.1:28443`，工程接入口为 `28450`、`28451`。中继使用独立 PostgreSQL（`25432`）、独立数据库和 TLS 机器身份；这些端口不是浏览器登录入口。
