## 3 启动和恢复本机验收服务

在主工作树 `/Users/hijacker/Documents/ChatGPT/InfraPro` 运行，已准备过的数据库与账号会保留：

```bash
node scripts/project-resource-acceptance/setup.mjs
node scripts/project-resource-acceptance/start.mjs
```

服务启动后，可另开终端运行 `node scripts/project-resource-acceptance/verify.mjs`，对初始准备数据执行只读范围与页面检查。已手工修改数据后，初始数量断言可能不再适用，不会自动重置数据。

setup 构建当前 API/CLI、迁移并同步/检查权限；bootstrap 只在本专用新环境首次执行，已存在 marker 时跳过。start 使用正常限流并监听上述两个端口，Ctrl+C 只停止服务，保留数据库与凭据。不要同时启动第二份相同端口服务。

仅在首次建立全新验收环境时，先用 `node scripts/project-resource-acceptance/start.mjs --seed-mode` 启动，再另开终端运行 `node scripts/project-resource-acceptance/seed.mjs`。seed 使用真实业务 HTTP 接口，并记录已完成步骤；完成后重跑不会重建或重置用户已修改的验收数据。准备完毕应停止 seed-mode，再用普通 start 启动。
