日期：2026-11-11。功能状态：Awaiting acceptance；自验见[验证记录](../verification/workspace-navigation-refactor.md)，人工验收尚未开始。

## 入口与操作

普通登录进入账号首页。首页、个人资料和账号安全没有业务侧栏；左上选择工作空间，右上提供页面搜索、主题及唯一账号菜单。首页原有卡片和内容保持不变。

在左上切换器输入租户或项目的名称 / 编号，按“全部 / 租户 / 项目”筛选；项目可按“全部 / 运行中 / 已归档”筛选。搜索由服务端完成，不只过滤当前已加载结果。项目按所属租户分组；单独的父租户标签不表示获得该租户访问资格。两类条目分别分页和重试，角色、归档和不可用原因显示在条目内。

正常条目进入对应资料页。停用租户提供“查看状态”，受限项目提供“查看本人状态”；这些操作不会授予业务权限。受限页的“重新选择”会在当前页面打开同一个选择器。取消不会离开当前页面，关闭后清空筛选；进入新空间后菜单跟随 URL。两个标签页可以分别留在不同空间。

旧 `/tenants`、`/projects` 及首页“我的租户”卡片会跳到首页并打开对应选择器。地址中的一次性参数会清除，后退不会反复弹出。租户“项目治理”、平台“租户管理”仍在原业务菜单；账号开户邀请仍属平台空间。

手机首页直接打开选择器。业务页面沿用导航抽屉；正文发起切换时先打开抽屉再显示选择器。选择后两层都关闭；Escape 只取消当前选择器并恢复触发器焦点，再关闭导航抽屉即可。

## 人工验收

完整 MA-01～MA-15 见[实施方案第 15 节](../requirements/workspace-navigation-refactor-plan.md#15-人工验收步骤)。建议按下列顺序执行，并分别记录通过 / 不通过及现象：

1. 普通登录：首页原内容完整、无侧栏或空白占位，右上菜单可进入资料 / 安全并返回首页。
2. 从左上依次进入租户、项目、平台：仅出现当前空间有权菜单；项目治理与平台租户管理仍可用。
3. 折叠业务侧栏后回首页再进入业务空间：首页无侧栏，业务空间保留折叠偏好。
4. 搜索名称 / 编号，切换类型与归档状态，加载更多：结果、角色和所属租户正确；受限条目可查看本人状态。
5. 访问旧地址、点击首页原卡片，关闭弹层后后退 / 前进：落点正确，不重复弹出、不循环。
6. 手机从首页及业务正文切换空间：焦点、输入、取消和关闭两层后的页面点击均正常；亮暗主题无横向溢出。
7. 两标签页停留不同项目，检查各自 URL / 菜单；从合法深链接登录仍返回原目标；租户邀请仍需明确确认加入，取消后可重新选空间。
