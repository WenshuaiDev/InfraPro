# 文档在线预览与人工验收

状态：Awaiting acceptance（预览功能专项自验通过）。自验结果及并行改动造成的整站检查限制见[验证记录](../verification/document-preview.md)，人工验收尚未完成。

## 使用与发布

在租户/项目的“文件与附件”或资料附件中打开文件，直接显示阅读器。预览与版本记录已合并：点击预览上方的版本按钮选择当前或历史版本，正文、版本说明与底部“下载原件”同步切换；历史版本旁可“返回最新版”或“还原此版本”。展开版本选择器才加载历史，可继续加载更多版本。具备原件下载资格才可预览，管理资格不代替读取资格；回收站不读取正文。

本次不迁移数据库、不重传既有文件、不增加转换 worker。执行 `pnpm install --frozen-lockfile` 和 `pnpm --filter @infrapro/console build`，发布完整 `apps/console/dist`。开发使用 `pnpm --filter @infrapro/console dev`。构建/开发脚本自动从固定版本依赖复制 PDF 字体、CMap、WASM、ICC 到公共目录；这些资源必须随 `dist/vendor/pdfjs` 一起发布，不能只复制 JS。所有阅读依赖在本地打包，部署环境无需访问第三方预览服务。

## 操作验收

| 格式 | 操作与预期 |
| --- | --- |
| PDF | 多页连续滚动；上一页/下一页、页码跳转；缩放/适合宽度/旋转；选择文本；搜索后前后定位并高亮；全屏及退出后仍处于附件详情 |
| Word `.docx` | 中文段落、标题、图片、列表、表格、页眉页脚可读；显式分页后可翻页/跳页；搜索定位；缩放/适合宽度/全屏 |
| Excel `.xlsx` | 切换工作表；保留原始行列编号；分页与搜索；点击列标排序并可恢复；点击单元格查看完整值和公式，方向键移动；合并区域可见；缩放/全屏 |
| CSV | 中文、带引号逗号/换行、双引号转义正确；编号前导零和以等号开头的内容原样显示；支持选择分隔符与编码；搜索/分页/单元格/排序/缩放/全屏 |
| TXT | 显示行号；分段分页；搜索命中跳到相应页及行；切换自动换行；字号缩放/编码选择/全屏 |

额外检查：附件详情不再显示概览/版本记录页签；替换文件后，在预览上方选择旧版本，正文和下载均为旧内容，还原会创建新版本；返回最新版立即显示最新正文。版本按钮可用 Enter 展开、方向键选择、Enter 确认，Esc 仅关闭菜单并返回按钮。加载更多失败后已加载版本仍保留，可重试。关闭/重开、退出/切换账号后不残留前一正文；缺少下载权限时不发起正文请求；阅读失败时仍有原件下载入口。375px 窄屏、深色、键盘 Tab/方向键和 Esc 可操作。支持原生全屏的浏览器进入系统全屏，否则使用覆盖全窗口的阅读对话框。

## 阅读边界

- 这是只读阅读，不提供 Office 编辑、公式重算、宏、外部链接数据更新或 OCR。XLSX 以数据表呈现，不渲染嵌入图表/图片和复杂打印版式；单元格显示文件内保存的格式化值，未保存的公式结果明确标记。
- Word 依照文档分节和显式分页；复杂浮动对象、缺失字体及自动分页可能与桌面 Word 有差异，正式版式以原件为准。扫描 PDF 可以浏览图像，只有存在文字层时才可选择和检索文字。
- 普通附件在线读取上限 100 MiB；PDF/Word 最多 2000 页；表格最多 100 个工作表、每表 20000 行/200 列、合计 500000 个单元格；TXT 最多 5000000 字符/100000 行。达到边界明确提示截断及下载，不将局部内容称为完整文件。
- 表格每页 50 行，TXT 每页 300 行；搜索范围为已载入的内容。Word 最多标出 2000 处匹配，达到上限显示 `+`。表格/文本解析 30 秒超时可重试；Word 30 秒、PDF 初始载入 60 秒后显示不可用提示。
- 当前上传格式中的 PPTX 仍只提供原件下载；旧二进制 DOC/XLS 不在允许上传列表。本轮支持 `.docx`/`.xlsx`。

## 自验命令

```sh
pnpm test:files:client
pnpm --filter @infrapro/console build
INFRAPRO_PREVIEW_PYTHON=/path/to/python3 pnpm files:preview:browser
pnpm test:files:http
```

浏览器测试通过真实文件服务建立隔离环境，默认不使用人工验收账号。样本生成器需要 Python 的 python-docx、openpyxl、reportlab 和 Pillow；也可先运行 `scripts/fixtures/document-preview-samples.py .artifacts/files/document-preview/samples`，随后省略环境变量。截图与结果写入 `.artifacts/files/document-preview/`。`INFRAPRO_FILES_SKIP_BUILD=1` 仅在刚完成对应源码构建后使用。
